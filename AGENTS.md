# Reglas para el agente
1. Lee START_HERE.md, SPEC.md y STATUS.md. Ejecuta una sola etapa solicitada; no avances automáticamente a la siguiente.
2. Sigue prompts/INDEX.md. Si no se indica etapa, toma la primera pendiente y comunica cuál ejecutarás.
3. Lee solo documentos/archivos relevantes; no releas todo el repo ni pegues archivos completos en el chat.
4. No cambies el stack ni añadas roles, ecommerce, IA, servicios cloud o colas externas.
5. Código real; no datos falsos ni éxitos simulados. Una función pendiente debe estar explícitamente deshabilitada.
6. Corre typecheck, pruebas pertinentes y build. Prueba el comportamiento nuevo, no solo que el código repite su implementación.
7. Actualiza STATUS.md y el contrato si procede: resultado, archivos relevantes, comandos, pendientes y próximo prompt. Reporte final <=12 líneas salvo bloqueo que requiera más detalle.
8. No borres datos ni modifiques otros proyectos de la VPS. No publiques ni cambies DNS sin autorización aplicable. No inventes accesos.
9. Secretos, medios, data, APK y firmas fuera de Git. Logs sin cookies, contraseñas, tokens o URLs firmadas.
10. No delegues a otros agentes salvo petición expresa del usuario. No omitas pruebas por ahorrar tokens si falta verificar un riesgo concreto.
